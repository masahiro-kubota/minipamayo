# Qwen2.5-VL Technical Report

Qwen2.5-VLに関する論文の要約です。本モデルはQwen vision-languageシリーズの最新フラグシップモデルであり、動的解像度処理、絶対時間エンコーディング、Window Attentionによる効率的なViTなどの革新により、視覚認識・文書解析・長時間動画理解・エージェント機能で大幅に改善されています。

## アブストラクト (Abstract)
**内容まとめ**:
Qwen2.5-VLは、基盤能力と革新的機能の両面で大きな進歩を達成したvision-languageモデルです：
1. **視覚認識の強化**: バウンディングボックスやポイントによる正確なオブジェクトローカライゼーション。請求書、フォーム、テーブル、チャート、図表、レイアウトからの構造化データ抽出。
2. **動的解像度処理と絶対時間エンコーディング**: さまざまなサイズの画像と長時間（数時間規模）の動画を処理可能。秒単位のイベントローカライゼーション。
3. **効率的なViT**: Window Attentionを組み込んだ動的解像度ViTをスクラッチから学習し、ネイティブ解像度を維持しつつ計算オーバーヘッドを大幅削減。
4. **3サイズ展開**: 3B/7B/72Bの3サイズで提供。72BモデルはGPT-4oやClaude 3.5 Sonnetに匹敵し、特に文書・図表理解で優れる。7B/3BモデルもLlama-3.1-70BやQwen2.5-72Bを上回る。

## 1. イントロダクション (Introduction)
**内容まとめ**:
大規模vision-languageモデル（LVLM）はAIにおける画期的なブレークスルーですが、現在のモデルは「サンドイッチクッキーの中間層」のように、多くのタスクで能力はあるものの卓越した性能には至っていません。Qwen2.5-VLでは、きめ細かい知覚能力の探求に注力し、エージェント的応用のための堅固な基盤を確立します。

技術的貢献は4つ：
1. **Window Attention**: ビジュアルエンコーダに導入し推論効率を最適化
2. **動的FPSサンプリング**: 時間次元にも動的解像度を拡張し、多様なサンプリングレートでの包括的動画理解を実現
3. **MRoPEの絶対時間対応**: 時間ドメインのMRoPEを絶対時間に整合させ、より高度な時系列学習を促進
4. **大規模高品質データ**: 事前学習コーパスを1.2兆→4.1兆トークンに拡大

主な特徴：
- **強力な文書パーシング**: マルチシーン、多言語、手書き、テーブル、チャート、化学式、楽譜などに対応したオムニ文書パーシング
- **正確なオブジェクトグラウンディング**: 検出、ポインティング、カウンティングで精度向上。絶対座標・JSON形式対応
- **超長時間動画理解と細粒度ビデオグラウンディング**: 数時間規模の動画を理解し、秒単位でイベント区間を抽出
- **コンピュータ・モバイルデバイスのエージェント機能**: 高度なグラウンディング、推論、意思決定能力

## 2. アプローチ (Approach)

### 2.1 モデルアーキテクチャ (Model Architecture)
**内容まとめ**:
Qwen2.5-VLは3つのコンポーネントで構成：

- **大規模言語モデル (LLM)**: Qwen2.5 LLMの事前学習重みで初期化。1D RoPEをMultimodal Rotary Position Embedding（絶対時間整合版）に変更。
- **ビジョンエンコーダ (Vision Encoder)**: 再設計されたVision Transformer（ViT）。2D-RoPEとWindow Attentionを組み込み、ネイティブ入力解像度をサポート。画像はパッチサイズ14、ストライド14で分割。
- **MLP Vision-Language Merger**: 4つの隣接パッチ特徴をグループ化し、2層MLPでLLMのテキスト埋め込み次元に射影。画像特徴シーケンスを動的に圧縮。

| 構成 | Qwen2.5-VL-3B | Qwen2.5-VL-7B | Qwen2.5-VL-72B |
|------|---------------|---------------|----------------|
| **ViT** Hidden Size | 1280 | 1280 | 1280 |
| **ViT** Layers | 32 | 32 | 32 |
| **ViT** Heads | 16 | 16 | 16 |
| **ViT** Patch Size | 14 | 14 | 14 |
| **ViT** Window Size | 112 | 112 | 112 |
| **ViT** Full Attention Blocks | {7, 15, 23, 31} | {7, 15, 23, 31} | {7, 15, 23, 31} |
| **Merger** In/Out Channel | 1280/2048 | 1280/3584 | 1280/8192 |
| **LLM** Hidden Size | 2048 | 3584 | 8192 |
| **LLM** Layers | 36 | 28 | 80 |
| **LLM** KV Heads | 2 | 4 | 8 |
| 学習トークン数 | 4.1T | 4.1T | 4.1T |

#### 2.1.1 高速で効率的なビジョンエンコーダ (Fast and Efficient Vision Encoder)
**内容まとめ**:
ネイティブ解像度入力に起因する計算負荷の不均衡に対処するため、ViTアーキテクチャを再設計：
- **Window Attention**: 大部分のレイヤーでウィンドウアテンション（最大ウィンドウサイズ112×112 = 8×8パッチ）を使用し、計算コストをパッチ数に対して線形にスケール。Full Self-Attentionは4レイヤー（{7, 15, 23, 31}）のみ。
- **2D RoPE**: 2D空間の位置関係を効果的にキャプチャ。動画入力にも対応するため3Dパッチ分割（14×14画像パッチ、2フレームの時間マージング）に拡張。
- **LLM準拠の設計**: RMSNorm、SwiGLU活性化関数を採用し、ビジョンと言語コンポーネント間の互換性を向上。
- **学習**: DataCompおよび社内データセットを用いてViTをスクラッチから学習。CLIP事前学習、vision-languageアライメント、end-to-endファインチューニングの複数段階。

#### 2.1.2 ネイティブ動的解像度とフレームレート (Native Dynamic Resolution and Frame Rate)
**内容まとめ**:
空間・時間の両次元で多様なマルチモーダル入力を効果的に処理：
- **空間次元**: 従来の正規化座標と異なり、入力画像の実際の寸法を使用してバウンディングボックス、ポイント等を表現。スケール情報を内在的に学習。
- **時間次元**: 動的FPS学習と絶対時間エンコーディングを導入。可変フレームレートにより動画の時間的ダイナミクスをより良く捕捉。MRoPE IDsをタイムスタンプに直接整合させる新手法で、追加の計算オーバーヘッドなしに時間の流れを理解。

#### 2.1.3 絶対時間に整合したMultimodal Rotary Position Embedding (MRoPE Aligned to Absolute Time)
**内容まとめ**:
Qwen2-VLのMRoPEを拡張し、時間情報の扱いを改善：
- MRoPEは位置埋め込みを3つの成分に分解: **temporal（時間）**、**height（高さ）**、**width（幅）**
- **テキスト入力**: 3成分すべてに同一の位置IDを使用（従来の1D RoPEと等価）
- **画像入力**: 時間IDは一定、高さ・幅に一意のIDを割り当て
- **動画入力**: フレームごとに時間IDが増加、高さ・幅は画像と同じパターン
- **Qwen2-VLとの違い**: Qwen2-VLでは時間位置IDが入力フレーム数に紐づいていたため、コンテンツ変化速度やイベントの絶対タイミングを考慮できなかった。Qwen2.5-VLでは**時間成分を絶対時間に整合**させることで、異なるFPSサンプリングレートの動画間でも一貫した時間アライメントを学習。

### 2.2 事前学習 (Pre-Training)

#### 2.2.1 事前学習データ (Pre-Training Data)
**内容まとめ**:
Qwen2-VLと比較して事前学習データ量を**1.2兆→約4兆トークン**に大幅拡大。データ構築は、生ウェブデータのクリーニング、合成データ生成等の手法を組み合わせ：

- **インターリーブド画像テキストデータ**: 4段階スコアリングシステム（テキスト品質、画像テキスト関連性、画像テキスト相補性、情報密度バランス）で高品質データを選別
- **絶対位置座標によるグラウンディングデータ**: ネイティブ解像度で実際の寸法に基づく座標値を使用。10,000以上のオブジェクトカテゴリ。バウンディングボックスとポイントグラウンディングの両方に対応。XML/JSON/カスタムフォーマットで合成
- **文書オムニパーシングデータ**: テーブル、チャート、数式、自然/合成画像、楽譜、化学式等を統合。**QwenVL HTMLフォーマット**で統一的に表現（レイアウト情報と座標をHTMLタグに統合）
- **OCRデータ**: 合成データ（ビジュアルテキスト生成エンジン）とオープンソースデータを組み合わせ。フランス語、ドイツ語、日本語、韓国語等多言語対応。チャートデータ100万件（matplotlib, seaborn, plotly）、テーブルデータ600万件
- **動画データ**: 動的FPSサンプリングでFPS分布を均等化。30分超の長時間動画にはマルチフレームキャプション合成パイプライン。ビデオグラウンディングは秒ベースとhmsフォーマットの両方でタイムスタンプを記述
- **エージェントデータ**: モバイル・ウェブ・デスクトップのスクリーンショットからキャプションとUIグラウンディングアノテーションを合成。function call形式で統一されたアクション空間。推論過程をアノテーション

#### 2.2.2 学習レシピ (Training Recipe)
**内容まとめ**:
事前学習は3フェーズに分割：

| ステージ | Visual Pre-Training | Multimodal Pre-Training | Long-Context Pre-Training |
|---------|-------------------|----------------------|-------------------------|
| データ | Image Caption, Knowledge, OCR | + Pure text, Interleaved, VQA, Video, Grounding, Agent | + Long Video, Long Agent, Long Document |
| トークン数 | 1.5T | 2T | 0.6T |
| シーケンス長 | 8192 | 8192 | 32768 |
| 学習対象 | ViTのみ | ViT & LLM | ViT & LLM |

- **Phase 1**: ViTのみを学習し、言語モデルとのアライメント基盤を構築。データソースは画像キャプション、視覚知識、OCR
- **Phase 2**: 全パラメータを解凍。インターリーブドデータ、VQA、マルチモーダル数学、エージェントタスク、動画理解、純テキストデータなど多様なデータで学習
- **Phase 3**: シーケンス長を32,768に拡大。長時間動画、長エージェント、長文書データを追加し、長距離依存と複雑な推論に対応
- **効率化**: GPU間のLLM計算負荷を均衡化するため、入力シーケンス長に基づく動的パッキング

### 2.3 ポストトレーニング (Post-training)
**内容まとめ**:
Supervised Fine-Tuning (SFT) と Direct Preference Optimization (DPO) の2段階アライメント：

#### 2.3.1 指示データ (Instruction Data)
- 約**200万エントリ**のSFTデータセット。純テキスト50%、マルチモーダルデータ50%（画像テキスト・動画テキスト）
- 単一ターン・マルチターン、単一画像・複数画像シーケンスなど多様な対話複雑度
- General VQA、Image Captioning、数学、コーディング、セキュリティ、文書/OCR、グラウンディング、動画分析、エージェントインタラクション等の専門サブセット
- 主に中国語・英語、補足的に多言語エントリ

#### 2.3.2 データフィルタリングパイプライン (Data Filtering Pipeline)
2段階のフィルタリング：
- **Stage 1: ドメイン別分類**: Qwen2-VL-Instagモデルで8つの主要ドメイン（Coding, Planning等）→30のサブカテゴリに階層分類
- **Stage 2: ドメイン特化フィルタリング**:
  - **ルールベースフィルタリング**: 反復パターン、不完全・切り詰められた応答、不適切コンテンツの除去
  - **モデルベースフィルタリング**: Qwen2.5-VL系列の報酬モデルで複雑さ、関連性、正確さ、有用性を多次元評価

#### 2.3.3 推論強化のためのRejection Sampling
- 数学的問題解決、コード生成、ドメイン特化VQAなど複雑推論タスクに適用
- Ground truthアノテーション付きデータセットから、中間版Qwen2.5-VLモデルで応答を生成し、正解一致のものだけを保持
- コードスイッチング、過剰な長さ、反復パターンの応答を除外
- CoT推論の各ステップが視覚・テキスト両モダリティを適切に統合しているか検証

#### 2.3.4 学習レシピ (Training Recipe)
- **SFTフェーズ**: ViTパラメータを凍結。画像テキストペア、動画、純テキスト、General VQA、Rejection Sampling、文書/OCR、グラウンディング、動画、エージェント関連の多様なマルチモーダルデータで微調整
- **DPOフェーズ**: 画像テキストと純テキストデータのみ。選好データを用いてユーザー意図への整合を最適化。各サンプルは1回のみ処理

## 3. 実験 (Experiments)

### 3.1 SOTAモデルとの比較 (Comparison with SOTA Models)
**内容まとめ**:
Qwen2.5-VLを Claude-3.5-Sonnet-0620、GPT-4o-0513、InternVL2.5、Qwen2-VL等と比較：
- **大学レベル問題**: Qwen2.5-VL-72BはMMMU 70.2、MMMU-Pro 51.1で以前のオープンソースSOTAを上回り、GPT-4o相当
- **数学**: MathVista 74.8（前SOTAの72.3を超える）、MATH-Vision 38.1
- **一般VQA**: MMBench-EN-V1.1で88.4（InternVL2.5-78BやClaude-3.5 Sonnetを上回る）、MMStar 70.8
- **高解像度実世界**: MME-RealWorld 63.2でSOTA
- **多言語テキスト認識**: MTVQA 31.7
- **小型モデルも好成績**: 7Bモデル・3Bモデルも同サイズ競合モデルを上回る

### 3.2 純テキストタスクでの性能 (Performance on Pure Text Tasks)
**内容まとめ**:
Qwen2.5-VL-72Bは、マルチモーダルだけでなく純テキストタスクでもSOTA級：
- **一般**: MMLU-Pro 71.2、MMLU-redux 85.9、LiveBench 57.0
- **数学・科学**: MATH 83.0（Llama-3.1-405Bの73.8やQwen2.5-72Bの83.1に匹敵）、GSM8K 95.3
- **コーディング**: HumanEval 87.8、MultiPL-E 79.5
- **指示追従**: IFEval 86.3
- Llama-3.1-70Bを大幅に上回り、パラメータ6倍のLlama-3.1-405Bに匹敵

### 3.3 定量的結果 (Quantitative Results)

#### 3.3.1 一般的なVisual Question Answering
**内容まとめ**:
- MMBench-EN-V1.1: 88.4%でInternVL2.5 (78B)やClaude-3.5 Sonnetを上回るSOTA
- MMStar: 70.8%で多様な言語コンテキストへのロバスト性を実証
- MME-RealWorld: 63.2で高解像度実世界シナリオでSOTA
- MuirBench: 70.7で複数画像理解タスクでリーディング
- 小型モデル（7B/3B）も競争力：MMStarで7Bが63.9%、3Bが55.9%

#### 3.3.2 文書理解とOCR (Document Understanding and OCR)
**内容まとめ**:
OCR、チャート、文書理解ベンチマークで包括的に評価：
- **OCRパーシング**: CC-OCR 79.8、OmniDocBench 0.226/0.324でSOTA
- **OCR理解**: AI2D 89.1、DocVQA 96.4、InfoVQA 87.3、ChartQA 89.5で高性能
- **OCR総合**: OCRBench_v2 61.5/63.7でGemini 1.5 Proを英語9.6%、中国語20.6%上回る
- OCRBench 885、SEED-Bench-2-Plus 73.0で以前のSOTAを大幅に上回る

#### 3.3.3 空間理解 (Spatial Understanding)
**内容まとめ**:
グラウンディング能力を参照表現理解、オブジェクト検出、ポイントグラウンディング、カウンティングで評価：
- **参照表現理解**: Refcoco系でGemini 1.5 Pro、Grounding DINO等を上回る（例: Refcoco_val 93.7、Refcoco_testA 95.6）
- **オープン語彙オブジェクト検出**: ODinW 43.1 mAPでほとんどのLVLMを凌駕
- **ポイントグラウンディング**: 67.5で、バウンディングボックスでは困難だった精密ローカライゼーションを実現
- **カウンティング**: CountBench 93.6で「detect then count」プロンプトによりSOTA（Gemini 1.5 Pro 85.5、GPT-4o 87.9を大幅に超える）

#### 3.3.4 動画理解とグラウンディング (Video Understanding and Grounding)
**内容まとめ**:
数秒から数時間規模の動画ベンチマークで評価：
- **動画理解**: LVBench 47.3、LongVideoBench 60.7、MVBench 70.4でGPT-4oを上回る
- **長時間動画**: MLVU 74.6、TempCompass 74.8で強力な長尺動画理解を実証
- **ビデオグラウンディング**: Charades-STA mIoU 50.9で、GPT-4o（35.7）を大幅に上回る
- 同期MRoPEによりタイムスタンプ参照、時間的グラウンディング、密なキャプショニングで優れた性能
- 評価時の最大フレーム数は768、動画トークン総数は24,576以下

#### 3.3.5 エージェント (Agent)
**内容まとめ**:
GUIグラウンディング・エージェントベンチマークで評価：
- **ScreenSpot**: 87.1%でGemini 2.0 (84.0%)、Claude (83.0%)と競争
- **ScreenSpot Pro**: 43.6%で新たなスタンダード（Aguvis-72B 23.6%、Qwen2-VL-72B 1.6%を大幅超過）
- **Android Control**: HighEM 67.36、LowEM 93.7で高い性能
- **AndroidWorld**: 35%（SoM）
- **MobileMiniWob++**: 68%で競争力
- **OSWorld**: 8.83で他モデル（GPT-4o 5.03、Gemini 2.0 4.70）を大幅に上回る
- Set-of-Mark（SoM）なしでもAndroidWorldやMobileMiniWob++で同等以上の性能を達成

## 4. 結論 (Conclusion)
**内容まとめ**:
Qwen2.5-VLは、マルチモーダル理解とインタラクションにおいて重要な進歩を達成したSOTA vision-languageモデルシリーズです。

主な成果：
- **視覚認識・文書パーシング・長時間動画理解**で強化された能力により、静的・動的タスクの両方で優秀
- **ネイティブ動的解像度処理と絶対時間エンコーディング**で多様な入力をロバストに処理
- **Window Attention**により解像度忠実度を犠牲にすることなく計算オーバーヘッドを削減
- **Qwen2.5-VL-72B**はGPT-4o、Claude 3.5 Sonnetに匹敵・凌駕（特に文書・図表理解）
- **Qwen2.5-VL-7B/3B**も同サイズ競合を上回り、エッジAIからハイパフォーマンスコンピューティングまで幅広い用途に対応
- 純テキストタスクでもQwen2.5 LLMの言語能力を維持
- ドメイン横断的な汎化とタスク実行で卓越し、知覚と実世界アプリケーションを橋渡しする次世代ベンチマークを確立
